# Share-copy scope

This folder is a newly curated copy, not a clone of the original working tree or its Git history. It contains source code, tests, configuration examples, descriptive result tables/plots, research preparation documents, a single author-written Overleaf progress fragment, and hashes of omitted inputs. No new model inference, data fetch or financial experiment was performed to prepare it.

## Included

- `src/finembed/`, `tests/`, selected `scripts/`, `configs/`, `pyproject.toml`, and an empty `.env.example` template.
- Five-company embedding cosine matrices, Top-2 overlap, TF-IDF cosine, and compact price PCA loadings/variance fractions derived from existing saved results. The share export checks every source result against its original run manifest.
- M4 closeout, corrected historical filing chronology, M5 route/decision documents, and the author's own progress paragraph.
- `results/PROVENANCE.json` with run/config IDs and SHA-256 values for omitted original SEC documents, model weights and ten Massive raw REST responses. The market data are available only from the vendor under the user's own entitlement.

## Intentionally excluded

- API keys, tokens, cookies, browser sessions, non-template `.env` files, local credentials, logs that might contain them, virtual environments, caches, model weights, and old archives.
- SEC raw submissions, extracted Item 1 text, chunk maps/token IDs and full document vectors. Their source identities and hashes remain in the reports/provenance.
- Massive raw response bodies, processed daily price bars, the 250×5 return matrix and 249×2 date-score series. Only compact descriptive derived outputs and source hashes are shared. No raw market-data redistribution right is asserted.
- Team Overleaf project sources, private annotations, correspondence, screenshots, earlier superseded reports and original Git history. The included `.tex` file is the author's own engineering-progress paragraph only.

The M4 closeout is an archived narrative about the original local evidence package. Its raw-data and run-path references do not mean those objects are present in this share copy. The repository uses no MIT or other default license because code-sharing terms have not been decided.
