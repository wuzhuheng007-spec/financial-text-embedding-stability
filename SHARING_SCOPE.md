# Sharing scope

This repository contains research software, tests, candidate configurations, aggregate engineering results and dated reports. Private development history is excluded from the 2026-11-13 publication snapshot, which descends from the existing public sharing branch.

Licensed WRDS exports, original filing text, weights, vector arrays, row-level private indexes, credentials, account screenshots, support correspondence and private decisions remain local. Links to ignored artifacts describe locally retained evidence and are not downloadable public files. File hashes document identity; they do not confer a redistribution license or prove provider completeness.

Candidate configurations retain their original bytes and status. Historical reports retain their dated limitations. Personal home-directory paths are redacted in publication copies; the source mapping records adapted files. Registered generic local-drive defaults in offline runner code are implementation defaults, not acquired data.

Formal M5 remains proposed and unfrozen. No financial training, prediction score or backtest was produced by this publication. No license is added or implied.
