\paragraph{Engineering progress (19 October 2026).}
We built a reproducible engineering demonstration using five real SEC Form 10-K filings. The pipeline preserves the original submissions and metadata, extracts Item~1 Business with source offsets, and produces document embeddings from a pinned pretrained model. We checked repeat inference with fixed weights and compared 128- and 192-token chunks; this is a descriptive sensitivity check rather than evidence across independent training seeds. A simple TF--IDF representation was fitted only to the five validated Item~1 documents. Using authenticated Massive historical daily bars, we retained raw responses and security mappings, computed 249 complete daily return observations from 250 price bars per security in the configured 2025 window, and fitted a centered two-component price PCA. The prices are split-adjusted; these returns exclude dividends and are not total returns. A separate, same-author read-only script checked hashes and recomputed returns and PCA relationships from saved raw responses. This small-sample demonstration does not establish the incremental financial value of text, predictive performance, or the absence of look-ahead bias; the formal task, universe, time split, controls, and metrics remain to be agreed.
