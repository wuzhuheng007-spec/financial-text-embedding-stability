## What the new output stages mean

The model emits **raw wire JSON** with semantic fields and body quotations, but without `input_binding` or character offsets. The host first checks the wire Schema and source-body hash. It then finds every quote by an exact, case-sensitive Unicode substring search. A missing or repeated quote blocks canonical construction; the host neither chooses a match nor rewrites the model's event or direction. If all quotes are unique, the host attaches the trusted input binding and computed offsets, then applies the unchanged canonical v1 validator. A valid no-quote output is separately counted as `NO_SPANS_REQUESTED`, never as a 100% quote success.

The terminal stage distribution is **7 `WIRE_SCHEMA_INVALID`**, **1 `JSON_PARSE_ERROR`**, **1 `QUOTE_UNRESOLVED`**, and **1 `INTERRUPTED_PROCESS_UNCLASSIFIED`** across ten attempted positions. Nine raw responses were saved; eight were JSON parseable. The single wire-valid response requested eight quotes: seven had exactly one original-body match and one had no match. Because the adapter refuses to construct a canonical object when any quote is missing, **0/1** wire-valid response was constructible; conditional canonical Schema and mechanical validity are **NOT_EVALUATED (0/0 constructed)**. `NO_SPANS_REQUESTED` and empty-record wire-valid responses were both **0/1**. These [stage counts and denominators](../results/news_grounding_runtime_20261114/inference_aggregate.json) describe engineering behavior, not company-event correctness.

The previous v3 run attempted 3/10 and saved two responses; this v4 run attempted 10/10 and saved nine, including one externally interrupted attempt. The [paired receipt](../results/news_grounding_runtime_20261114/paired_comparison.json) has only one position with two completed responses. The new prompt's median token count was **1,515.5 lower** than v3 across the fixed ten inputs. Prompt length, wire contract, host adapter and requested attention implementation all changed together. The v4 run recorded no PyTorch OOM, but the concurrent native crashes and changing shared GPU use prevent an SDPA causal claim. The original pre-run runner and recovery runner were distinct code hashes; [recovery validation](../results/news_grounding_runtime_20261114/recovery_validation.log) used eight synthetic tests, [postlaunch validation](../results/news_grounding_runtime_20261114/postlaunch_recovery_validation.log) used one focused synthetic test, and [post-run validation](../results/news_grounding_runtime_20261114/post_run_validation.log) used 20 focused synthetic tests. The [pre-run suite](../results/news_grounding_runtime_20261114/pre_run_validation.log) comprised 52 tests including prior tests; these test invocations overlap and are not independent extraction trials. The [final audit closure](../results/news_grounding_runtime_20261114/final_audit_closure_receipt.json) records byte-identical v3, v4 and paired read-only replays.

The v3 **0/3 model-supplied offset matches** and any v4 host-computed offset checks measure different processes. Host-added binding is not a model hash-copying skill. Exact substring presence is not evidence that the quotation supports the claimed company, event or impact direction. The new prompt, wire protocol, adapter and requested SDPA implementation changed together, so this development run cannot isolate one component's effect. `sdpa` does not by itself establish which PyTorch kernel ran or that OOM was solved; see the versioned [Transformers attention interface](https://huggingface.co/docs/transformers/v4.57.1/attention_interface) and [PyTorch SDPA documentation](https://docs.pytorch.org/docs/2.11/generated/torch.nn.functional.scaled_dot_product_attention.html).

## Research boundary and next work

The first ten source-order articles were already used during field and prompt development. Independent human company-event adjudication and a separate event-grouped sample are still required for extraction-quality claims. Historical publication timing, company–security identity and an accepted financial protocol remain separate prerequisites. Inspect the seven wire-Schema failures and the one missing quote using private responses while retaining their raw text and stages. Investigate the native interruption and measured GPU-memory conditions without asserting a single cause. Any prompt or runtime change needs another explicit version and independent evaluation; this turn performed one bounded v4 run. No human extraction-quality, historical financial admission or return experiment was started.
