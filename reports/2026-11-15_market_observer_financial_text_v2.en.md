## Input, cards, and the first negative content check

The original v2 parser produced **2,398 provenance blocks** from the 16 saved documents: **747 paragraphs, 1,645 table rows, and six headings**. It keeps raw HTML DOM paths separate from clean-text offsets and records whole-block selection. Its 20,000-character-per-event adapter selected **352 blocks** and explicitly omitted **2,046** across the eight events. The [build receipt](../results/market_observer_financial_text_v2_20261115/build_redacted.json) and [format validation](../results/market_observer_financial_text_v2_20261115/format_validation_redacted.json) bind these counts; source text and full blocks remain private. The old 128-term TF-IDF input path is unchanged. The new feature interface is format-checked and marked `NOT_FITTED`.

Deterministic rules generated **71 candidate facts**. Separate `CODEX_REVIEW` against the saved exhibits marked **60 source-supported** and **11 ambiguous**, without overwriting the automatic candidates. The eight historical cards retain source document hashes, SEC locations, original numeric strings, financial periods, units, GAAP status when supported, and explicit unknown fields. **32** comparisons are bound to the immediately preceding fiscal quarter in the same source table; **eight** guidance bounds are marked code-derived with their input candidate IDs. No prerelease consensus or “beat” label is created. The unresolved items include combined NVIDIA equipment/intangible purchases, free-cash-flow unit or period, and Micron segment-table scale. These are development cards, not general extraction-accuracy evidence.

The first actual training-only retention comparison found a **regression in the model-ready selected text**. On the **71 reviewed candidate facts**, the old input retained **34 strictly complete** evidence sets and original v2 retained **18**. The stricter grade requires the metric, value, period, unit, necessary accounting basis, and applicable source-bound previous-quarter context. Original v2 recovered **zero** formerly incomplete facts to that grade; **37 of the 60** source-supported facts still had incomplete model-ready evidence. Four of the **72 topic-level spans** moved from old `LOST` to v2 `COMPLETE`, but topic spans have a different denominator and do not establish complete fact recovery. The [first retention receipt](../results/market_observer_financial_text_v2_20261115/retention_redacted.json) preserves document, fact, and **483 assessed field-slot** denominators separately.

The concrete defect is a missing table-header link. In the [Micron June 2025 release](https://www.sec.gov/Archives/edgar/data/723125/000072312525000019/a2025q3ex991-pressrelease.htm), `FQ3-25`/`FQ2-25` headers and the “in millions” row precede the revenue figures. Original v2 selected the numeric row but did not recognize the `FQ` period form or carry both headers into that selected row. A later NVIDIA cash-flow table also places its period header after the parser's first-four-row search limit. This is a real input-contract failure under the frozen training checklist. The first negative result and parser bytes remain preserved.

## Versioned v2.1 correction and remaining adapter limit

A [separate v2.1 configuration and change note](../configs/market_observer_financial_text_v21_CHANGE.md) froze one training-only correction before rebuilding: recognize explicit `FQn-yy` headers, scan later statement header rows, and copy source table headers and value rows into actual clean block text. The [v2.1 comparison receipt](../results/market_observer_financial_text_v21_20261115/retention_redacted.json) keeps the same **71 fact** and **483 field-slot** denominators. In the **complete private parsed-block store**, strict fact evidence rose from original v2's **18/71** to **34/71**, matching the old builder's **34/71**. The broader topic-span measure rose from original v2's **47/72** to **67/72** in complete blocks. A separate [source-locality audit](../results/market_observer_financial_text_v21_20261115/source_audit_redacted.json) matched all **189 selected table rows** and **165 copied header contexts** to the hashed training originals, with zero locator mismatches. This establishes a source-preservation gain inside the parsed store; it does **not** establish better model input or independent semantic accuracy.

With the fixed budget applied, v2.1 selected **336 blocks**, rather than v2's 352, and the strict model-input count remained **18/71**. Its selected topic spans improved from v2's **43/72** to **52/72**; selected previous-quarter period fields improved from **16/32** to **32/32**. Yet **35/60** source-supported facts still have incomplete selected input, and no formerly incomplete fact became strictly complete. For the Micron June 2025 revenue row, the selected block now carries the source unit and `FQ` headers, but the introductory sentence giving the fiscal period end date was omitted. The full parsed store passes this fact; the selected input is still partial. Header copies also increase block length and displace other rows. This limits the current adapter; no return model was fitted to conceal or reinterpret it. The original v2 and v2.1 receipts remain separately versioned, rather than averaging their incompatible states.
