# Personal real-time Demo v1.1: page, quote deduplication and watchlist controls

**Run date:** 16 November 2026, Asia/Shanghai. **Portal:** <http://127.0.0.1:8765/> (loopback only; use the existing owner login). Baseline commit: `fccb45807fad061c39e6c94bbb72e21eaca4fa46`. No account reset, research download, model run or trade was performed.

## Observed result

- Online SQLite backups of the personal database and private feed cache preceded the changes. The final [redacted runtime receipt](../results/quant_portal_personal_feed_v11_20261116/runtime_redacted.json) compares the current database with the backup: one account, six watchlist rows, one settings row and 14 historical fact cards are unchanged. Private backups and source records stay local.
- The former quote writer hashed the whole push payload. Auxiliary changes created rows even when the source time and displayed last price were unchanged. The six-symbol legacy cache had 3,139 rows, with one distinct source time and displayed price per symbol. At the 09:54:55 Asia/Shanghai receipt, v1.1 had rejected 2,232 repeat packets and the row count remained 3,139. Legacy rows were retained. A newer source time with the same price remains eligible; a changed price at the same source time remains a version. Latest display selection uses source time before receipt time.
- Both provider threads expose heartbeat and business success separately. moomoo also exposes the last push, last newly inserted quote and latest quote source time. The six TQQQ, QQQ, SOXX, SPY, NVDA and MU subscriptions had server acknowledgement. The state was `CONNECTED_MARKET_CLOSED`; the latest quote source time was 2026-11-13T22:00:00.063Z. These are old quotes, not current trades. Currency, delay and the account-wide quota remain unknown.
- Jin10 counts business attempts before a call and separates protocol handshakes, business successes and failures. A latest-page poll does not prove a complete feed; a pair of pages without overlap is flagged as a possible coverage gap, without unlimited pagination. The receipt records 16 v1.1 business successes, zero v1.1 business failures and 92 cached flashes. The 51 daily attempts include only a lower bound from the legacy counter, so they are not a precise all-time attempt count. A flash is marked as Jin10 reporting with the original publisher unknown and cross-check pending.
- Watchlist membership is separate from quote subscription. The owner can subscribe or stop a verified code; when the local six-key budget is full, a replacement must be chosen explicitly. The page waits for the worker's acknowledgement. A bounded real MU stop/resume probe returned both acknowledgements and restored all six choices ([redacted probe](../results/quant_portal_personal_feed_v11_20261116/subscription_probe_redacted.json)). SNDK, SK hynix and SpaceX are independent news interests and do not create synthetic quotes.
- Browser polling reads only the local cache every five seconds. New flashes show a notice while the owner reads older entries instead of moving the page. An [isolated Edge browser check](../results/quant_portal_personal_feed_v11_20261116/browser_visual_isolated_redacted.json) on the same code found no whole-page horizontal overflow at desktop 1440px or mobile 390px. Synthetic flashes in the copied test database exercised the notice. That browser had no live worker and does not constitute an observed owner-browser session. The current owner route returned 200 and the anonymous route 302 in the [page readback](../results/quant_portal_personal_feed_v11_20261116/portal_readback_redacted.json).

The feed was stopped and restarted with its cached data and six selections retained. Current PIDs must be checked with the local status commands. Market-open source-time progression remains untested; the [Chinese personal guide](../docs/quant_portal/personal_user_guide.zh.md) provides a manual observation command. Six cache unit tests and the full 28-test Django suite passed; the six focused Django tests are included in the 28 and are not added again. Software, browser and real-provider evidence are separate in the [plan–actual ledger](../results/quant_portal_personal_feed_v11_20261116/plan_execution.csv).

The official [moomoo subscription guide](https://open.moomoo.com/api/quote/push/subscribe) documents acknowledgements, unsubscribe behavior and account-dependent quotas. Its [push format](https://open.moomoo.com/api/quote/push/data-format) supplies the millisecond source timestamp; the quote example does not supply currency or a delay flag. The [Jin10 MCP guide](https://mcp.jin10.com/app/doc.html) lists `list_flash` and an example structure; this run still binds parsing to the negotiated schema and actual response.

**Remaining limits:** No live owner-browser session or market-open progression was observed. Actual account quotas and Jin10 historical completeness are unverified. Financial input v2.5 remains `REJECTED_CANDIDATE`; model inference, return prediction and trading were not run.
