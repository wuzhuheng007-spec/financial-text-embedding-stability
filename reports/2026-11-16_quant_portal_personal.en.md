## What works locally

The independent [Django application](../apps/quant_portal/README.md) has local start/status/stop commands, account registration through a one-time invite, login, POST logout, editable user-owned watchlists, personal time-zone settings, source-linked historical earnings cards, and an explicit no-feed state. The loopback server was left running at `http://127.0.0.1:8765/`; its readiness endpoint and CSS returned HTTP 200 after the Windows process-tree and static-file fixes. The unconsumed owner invite remains only in ignored `apps/quant_portal/var/personal_invite.txt`; the user chooses a password at first registration. No account or browser password was placed in Git or a report. The [operations receipt](../results/quant_portal_20261116/ops_receipt_redacted.json) distinguishes the final working start/stop/status path from earlier corrected failures.

The first personal account seeds **six editable symbol candidates**, with no implied live identity or quote. The local database contains **11** pinned, previously redacted NVDA/MU fact summaries from [input v4](../results/market_observer_financial_text_v2_20261115/fact_cards_v4_redacted.json), bound to its SHA-256 in the [ops receipt](../results/quant_portal_20261116/ops_receipt_redacted.json). The two selected historical SEC earnings exhibits, [NVIDIA Q4 FY26](https://www.sec.gov/Archives/edgar/data/1045810/000104581026000019/q4fy26pr.htm) and [Micron FQ2-26](https://www.sec.gov/Archives/edgar/data/723125/000072312526000004/a2026q2ex991-pressrelease.htm), were reopened for a same-team field/context spot-check; the [11-row source receipt](../results/quant_portal_20261116/fact_source_web_check.json) records each value, period, basis and source locator. The app retains basis and currency where supported and shows `UNKNOWN` otherwise. These are dated `CODEX_REVIEW_DEVELOPMENT` summaries, not independent human gold, current financial results, or model output.

The application makes **zero provider calls on page loads**. It displays no fabricated prices. Moomoo and Jin10 public output are off by default; the [rights register](../docs/quant_portal/source_rights_register.md) separates personal access, server collection, cache, invited-user display, AI use and redistribution. Jin10's [agreement](https://flash.jin10.com/agreement) and [copyright notice](https://www.jin10.com/about/index.html) restrict unauthorized dissemination. Moomoo's [terms](https://www.moomoo.com/terms) restrict market-data redistribution; direct opening was rate-limited in this turn, so no new grant is inferred. An invitation or free access is not a provider display license.
