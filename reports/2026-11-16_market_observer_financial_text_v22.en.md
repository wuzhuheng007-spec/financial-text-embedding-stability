# Financial evidence input v2.2: fixed-budget regression

**Executed 16 November 2026, Asia/Shanghai.** This is a content-engineering comparison on previously saved NVIDIA and Micron training-period SEC material dated 2025-04-01 through 2026-03-31. It uses eight earnings exhibits, eight accession-matched primary filings and eight event groups. The [final preflight](../results/market_observer_financial_text_v22_20261116/preflight_r3_redacted.json) records the source manifest, code, configuration and reference hashes; the [v2.2 configuration](../configs/market_observer_financial_text_v22_20261116.json) freezes the 20,000 Unicode-character limit per event. The prior [v2/v2.1 report](2026-11-15_market_observer_financial_text_v2.en.md) and [v2.1 result](../results/market_observer_financial_text_v21_20261115/retention_redacted.json) remain unchanged.

## What was built and checked

The v2.2 adapter serializes numbered, shared context and candidate evidence groups into model-visible text. The single real build selected **147 groups** across the eight events. The serialized event inputs used **9,068–17,879 characters** each, below the fixed budget. It omitted **231 groups**: **109** for missing required context and **122** for unresolved context; **zero** were omitted for budget. **338** selected source fragments were checked against saved raw-document DOM locations. These are engineering locator checks, not confirmation that a financial fact is correct. The [build receipt](../results/market_observer_financial_text_v22_20261116/build_redacted.json) gives event-level counts and input hashes. Raw excerpts and full serialized inputs remain local.

The frozen candidate ledger contains **71** facts. Separate same-executor source review marked **60 source-supported** and **11 ambiguous**; the ambiguous entries remain unconfirmed. The [prior loss-stage receipt](../results/market_observer_financial_text_v22_20261116/loss_stage_redacted.json) classified the earlier v2.1 selected-input losses. Its **25** “omitted by budget” entries describe that earlier selection, not the v2.2 omissions above. The [retention comparison](../results/market_observer_financial_text_v22_20261116/retention_redacted.json) applies the same fragment-based completeness check to old, v2.1 selected and v2.2 selected text:

| Fixed denominator | Old input | v2.1 selected | v2.2 selected |
| --- | ---: | ---: | ---: |
| Strictly complete visible evidence, among 71 candidates | 34 | 18 | 8 |
| Strictly complete visible evidence, among 60 source-supported candidates | 34 | 18 | 8 |

The second line is a restricted denominator, not another set of successful facts. v2.2 regressed under the frozen check. **26** source-supported entries complete in the old input are incomplete in v2.2, including the saved June 2025 Micron revenue, EPS and gross-margin rows. The check also shows **zero** source-supported facts with all required elements in one explicitly bound v2.2 group: **46** have no single complete bound group, **10** have an unresolved footnote relation and **four** have known fields but unknown source basis. The eight fragment-level “complete” results must therefore **not** be read as eight verified, model-ready facts. No v2.2 input is promoted into the personal fact-card display or prediction path.

### Candidate-specific failure diagnosis

A **post-run, read-only** [diagnostic](../results/market_observer_financial_text_v22_20261116/postrun_loss_diagnosis_redacted.json) traced all 71 reviewed value locations through the saved source blocks. Of those, **27** map to a selected value group, **40** to an omitted value group (**34** unresolved context and **six** missing required context), and **four** to a matched block that was not made into a group. Among the 60 source-supported candidates, **24** map to selected and **36** to omitted groups. These candidate counts have a different denominator from the 147 selected and 231 omitted **groups** above. No candidate group was omitted for budget. For each of the eight fragment-level “complete” entries, the period appears elsewhere in the same document but is not bound to the selected numeric group. The diagnostic maps saved excerpts by DOM/text and is not a new source review; text-only or multiple matches and a row with a different value column can remain ambiguous. Its [corrections receipt](../results/market_observer_financial_text_v22_20261116/postrun_diagnosis_corrections.json) retains two diagnostic-script errors and confirms that the frozen adapter and comparison were not rerun.

## Limits and next action

This reuses training materials after the rule designer had seen April–May validation results. It is neither independent extraction testing nor a financial return comparison. The original source review is a same-team `CODEX_REVIEW`, and a DOM match proves location only. No April–July source body or label was read in this round; there was **no download, model fit, model inference, new return label, backtest or trade**. Formal M5 admission remains `NOT_RUN`. The private personal portal and its historical cards were not changed; neither dot nor the public page was updated.

The next single engineering issue is **binding the metric, value, period, unit and accounting basis in one model-visible evidence group without discarding the row**. First use the frozen 60 source-supported training candidates to inspect the failed bindings and revise the generic relationship rule; preserve this negative v2.2 result as the comparison baseline. Do not use the exposed validation or contaminated test intervals to select a repair.
