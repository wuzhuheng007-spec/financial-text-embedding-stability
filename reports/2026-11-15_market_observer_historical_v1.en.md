## Goal and actual data

The frozen source window was **2025-04-01 through 2026-07-31**. The official moomoo [historical K-line](https://open.moomoo.com/api/quote/basic-data/history-kline) API returned one complete page of 335 US daily bars for each pilot security, TQQQ, NVDA and MU, at both unadjusted (`autype=0`) and forward-adjusted (`autype=1`) settings. After that pilot succeeded, QQQ, SOXX and SPY each returned 335 unadjusted bars. All six date sets matched the 335-day US trading-calendar response; six as-of queries resolved the requested codes on 2025-04-01. These checks do not prove identity continuity on every later date. The [price receipt](../results/market_observer_historical_20261115/price_probe_redacted.json), [ETF expansion](../results/market_observer_historical_20261115/etf_expansion_redacted.json) and [identity receipt](../results/market_observer_historical_20261115/historical_identity_redacted.json) bind counts and hashes to the privately retained raw responses and request configurations.

The price work made **23 bounded moomoo business calls with zero retries**. The documented [history-quota endpoint](https://open.moomoo.com/api/quote/quotas/history-kline) returned business code `-3`, parsing `quotas` as a symbol; the account's remaining quota is unknown. The six-series expansion stopped there. The rest of the requested watchlist, including SNDK, SK hynix and SpaceX, has **no acquired historical price series in this run**. No other issuer's history was spliced in; [SpaceX's issuer release](https://ir.spacex.com/updates/releases-details/2026/Space-Exploration-Technologies-Corp--Announces-Closing-of-Initial-Public-Offering-Including-Full-Exercise-of-Underwriters-Option-to-Purchase-Additional-Shares-2026-RgoR-Y1Vwh/default.aspx) dates SPCX trading from 2026-06-12, so earlier SPCX bars would remain missing. The provider's `time_key` maps to the market date's local midnight, not a close or first-availability instant, and the returned `time_zone` values were `-4/-5` despite the current documentation describing minute offsets. Alignment therefore uses the date field, not `time_key` as a decision clock.

The [corporate-action receipts](../results/market_observer_historical_20261115/corporate_actions_redacted.json) ([alignment check](../results/market_observer_historical_20261115/action_alignment_redacted.json)) record dated provider split and dividend lists for the three pilot securities. TQQQ's 2:1 split effective before the 2025-11-20 open is independently supported by [ProShares' announcement](https://www.proshares.com/press-releases/proshares-announces-etf-share-splits5). Raw TQQQ close-to-close prices across that date would create a mechanical drop. The model below uses same-security, same-day open-to-close direction and ratio features on the retrospectively forward-adjusted series. It does not estimate dividend-inclusive total return; remaining action and historical-availability questions are open. Raw provider prices and action responses remain in ignored local `artifacts/` under [moomoo's market-data terms](https://www.moomoo.com/terms).

## Frozen first learning run

The requested label is the **next session's open-to-close direction**. For label session *t*, price/volume features stop at session *t−2*, before the entire preceding session *t−1*; no current-day or preceding close is used. A predicts each security's training-majority direction. B fits per-security L2 logistic regression on trailing 1/5/20-session price returns, 20-session return volatility and 1/5-session volume changes. Training-only standardization and the frozen L2 grid `{0.1, 1, 10}` were used; validation balanced accuracy selected `10` for each security. Label-date splits are training through 2026-03-31, validation April–May 2026 and test June–July 2026. Each pilot has **229 training, 41 validation and 43 test rows** after the within-window feature lookback. The [public frozen configuration](../configs/market_observer_historical_v1.json) exactly matches the private run-config SHA-256. Exact source/config hashes, class counts, selected parameters and private prediction-file hashes are in the [v3 redacted result](../results/market_observer_historical_20261115/price_direction_v3_redacted.json).

| Security | Test n | A accuracy | A balanced accuracy | B accuracy | B balanced accuracy |
| --- | ---: | ---: | ---: | ---: | ---: |
| TQQQ | 43 | 39.5% | 50.0% | 39.5% | 49.0% |
| NVDA | 43 | 46.5% | 50.0% | 55.8% | 57.7% |
| MU | 43 | 46.5% | 50.0% | 44.2% | 47.5% |

These are descriptive results for **three correlated development securities**. On validation, B's balanced accuracy was below A's 50.0% for every pilot: TQQQ 44.8%, NVDA 37.6%, MU 47.8%. B's contaminated test balanced accuracy exceeds A's for NVDA, but not for TQQQ or MU; this does not establish general predictive value. C (B plus news text) was **NOT_RUN** because a complete, rights-eligible historical news corpus with qualified availability times was not obtained. In particular, unobserved articles were not encoded as neutral or zero.

The [contamination receipt](../results/market_observer_historical_20261115/test_contamination_redacted.json) records that an earlier, now superseded close-to-close regression inspected June–July labels before the user supplied this exact classification protocol. A first direction implementation also generated test predictions for all validation-grid candidates before selection; its [v2 result](../results/market_observer_historical_20261115/price_direction_v2_redacted.json) and code are preserved. V3 corrected the procedure so grid candidates see training and validation only, and the selected model predicts the test once. The June–July interval nonetheless is **contaminated and cannot be called an untouched independent test**. No tuning was based on its v3 labels. Earlier post-window NVIDIA/CoreWeave/CPI development inputs were excluded. The old [exploratory receipt](../results/market_observer_historical_20261115/price_baseline_redacted.json) is retained rather than relabeled as this result.
