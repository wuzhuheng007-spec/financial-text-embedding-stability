## Evidence levels

| Level | What it can establish | What it cannot establish |
| --- | --- | --- |
| Bound source bytes and saved projection | Exact local file identity, header presence, literal values, record references and observed date intervals after a successful local read and saved-output check. | Supplier universe completeness, release vintage, permission, or a research rule. |
| Current public CRSP definitions | A reference meaning for a named CIZ field or flag. | That the user's saved WRDS extract used the same release, field coding, endpoint convention or complete flag dictionary. |
| Historical applicability evidence | A source-defined attribute value and date range can be associated with a particular issue or issuer at a target time, subject to its documented endpoint semantics. | A CIK-to-issue effective interval when the CIK-CUSIP table gives only first and last filing observations. |
| Research decision | Predeclared security eligibility, one-primary-issue policy, event-time market rule, canonical price and missing/exit mask. | Proof of source identity or data quality by itself. |

Report separate denominators at raw row, derived key, issue and event levels. Keep conflicts and undefined values visible. No returns, labels, scores or backtests are calculated in this inventory.
