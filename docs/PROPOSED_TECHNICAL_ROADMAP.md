# Proposed technical roadmap (not a frozen protocol)

**Source boundary.** This plan synthesizes the written project request, saved M5 draft, M6–M10 method documents, and the evidence traces in this repository. The route image mentioned in the handoff was not available for inspection. No image-derived idea is claimed here; every future step below is **PROPOSED** and requires the indicated gate.

Workstreams are linked by evidence requirements, not one mandatory linear sequence. In particular, the fixed-text stability mainline can continue as engineering research without declaring historical trading times. Any financial extension requires a separate temporal and market-data gate.

| Workstream / research question | Prerequisite | Proposed method | Evaluation | Expected artifact | Completion criterion | Unresolved decision |
| --- | --- | --- | --- | --- | --- | --- |
| Data: which exact quarterly texts are admissible? | Preserve raw, primary, extracted and structured versions with hashes; finish company-specific review | Complete the five-company 10-Q Item 2 review; bind each decision to one version; keep GOOGL sparse header mappings and other limitations explicit | Source-to-extract span/hash checks, table/period review, human acceptance ledger | Versioned admissibility register and exclusion report | Exact input identity and review state visible for every admitted document | Who accepts remaining company versions; whether limited-use derivatives are eligible for each task |
| Retrieval: can saved disclosure evidence be found reliably? | Fixed admissible corpus and frozen questions/anchors independent of method tuning | Researcher-check source questions; define a held-out set including cross-company, cross-document, cross-period, unsupported and limitation-disclosure cases | Predefined source-span coverage, ranking, citation evidence, abstention and failure categories; report denominators and dependency | Frozen question set, retrieval outputs, error taxonomy | Held-out results and failures reproducible from exact index and source versions | Target uses, test-set construction, relevance judgments and metric thresholds |
| Representation stability: how sensitive are fixed-text company vectors? | Versioned same-section text; locked encoder/tokenizer and preprocessing | Compare chunk sizes/boundaries, equal vs token weights, lexical length controls and structured serialization; then expand texts/models | Matched-document similarity changes, rank/top-k stability and uncertainty at document/company level; separate post hoc probes | Run matrix, vector/mapping hashes, descriptive report | Every comparison changes a stated factor and reports coverage, missingness, and limits | Formal corpus, model revisions, perturbation grid, analysis unit and uncertainty plan |
| Generation: does a local generator produce grounded answers? | Retrieval evaluation; resource/license/runtime review; pinned model and receipt | Add a bounded local generator only after local compatibility and source-isolation checks | Human-graded answer support, citation correctness, unsupported-question handling and cost/latency | Separate generation run and failure ledger | Real inference and evaluation saved; no claim from an interface alone | Model, compute budget, safety and human rubric |
| Genuine MoE: is expert routing useful under controlled conditions? | Verified sparse-expert model, local runtime, fixed contexts/budget and matched baselines | Run a separately identified MoE experiment, controlling model scale, training data, context, hardware and inference budget as feasible | Grounding and resource metrics under an explicit comparison design | Pinned model receipt, execution logs and qualified comparison | Actual routed inference with interpretable controls | Whether this extension is worth the resources; fair comparator design |
| Financial extension: does text add value beyond prices? | **Researcher-frozen M5 protocol**, point-in-time text availability and revision evidence, licensed adjusted price data | Only then set decision time, train/test chronology, past-only vocabulary/IDF/scaling/PCA, price and lexical controls, missing/delisted handling, dividends and costs | Predeclared prediction/risk metrics and uncertainty at the correct independent unit | Formal, versioned experiment ledger | Complete leakage audit and out-of-sample results under the approved design | Main task, sample/time, returns definition, horizons, baseline, costs, metrics and inference plan |

Fixed-weight repeat inference checks deterministic execution; it is not a training-seed study. The five-company M6/M7 and two-document M10 outputs neither choose a winning method nor prove financial benefit. All numerical claims in a future paper should link to a result field, run configuration, source version and code revision.
