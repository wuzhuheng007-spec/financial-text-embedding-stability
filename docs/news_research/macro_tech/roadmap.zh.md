# 宏观与系统性事件 → 大盘与科技股传导研究

更新：2026-11-15，Asia/Shanghai。用户已明确新的研究关注范围；下列实施参数为研究方案，不是已运行结果。

## 1. 研究问题与范围

研究哪些宏观、政策、流动性、地缘和关键科技企业事件会改变市场预期，以及它们可能通过哪些渠道影响美国大盘、科技行业及具体公司。事件是主单位，公司是受影响对象；不再以单一ticker的CSV前十篇作为核心语料。

原来的表示稳定性问题保留：固定事件和证据，改变模型/提示词/分块后，事件分类、影响路径、公司暴露与下游风险预测改变多少？先形成有研究价值的事件材料，再开展模型比较。

用户提到的高管变动、政策转向、加息概率、融资成本等均是需求示例，不作为真实已发生事件。没有核验的数值、个人指控或传闻不能写入事实表。

## 2. 事件分类与科技暴露

| 类别 | 优先事件 | 待检验渠道 |
|---|---|---|
| 宏观数据 | CPI、核心通胀、就业、工资及修订 | 政策预期、实际利率、增长需求 |
| 货币政策 | 决议、指引、重要讲话、利率预期重估 | 折现率、流动性、美元、融资条件 |
| 科技与产业政策 | 芯片出口限制、关税、数据中心许可/电力政策、选举后的具体措施 | 市场准入、算力供需、建设成本、资本开支 |
| 地缘与能源 | 航运通道中断、制裁、冲突升级、能源供应变化 | 能源价格、运输、通胀与风险溢价 |
| 金融稳定与杠杆 | 信用利差、保证金压力、被迫去杠杆、银行/融资压力 | 风险偏好、资金流动、跨市场传染 |
| 科技产业链关键事件 | 融资条款、资本开支变化、重要客户/供应商冲击、高管治理事件 | 融资约束、订单、交付能力、产业链信心 |

初期关注美国大盘与科技板块，兼看利率、美元、能源、波动率与信用作为渠道变量。公司候选包括用户关心的NVDA、CRWV及有证据关联的半导体、云、数据中心、电力/散热企业；候选ticker不是已确认的历史证券映射。公司级事件不自动升级为系统性事件，必须说明其市场集中度、融资或供需渠道。

不依据政党名称直接设定影响方向，不依据竞争关系自动赋负面标签，不把韩国某类投资者的杠杆变化直接等同于美股抛售。每一步都需要来源或明确标为假设。

## 3. 输出：证据支持的事件卡，而非单一情绪分数

每张卡分为四层：
1. **事实层**：发生/公布了什么、何时首次可知、来源、版本、原文定位、事实/传闻/预测状态。
2. **预期层**：实际值、公布前预期、前值和修订；概率对应哪次会议、哪种动作、哪个时点。共识缺失则未知，不以修订后数据或后来报道补入历史输入。
3. **传导层**：利率/增长/流动性/能源/信用/供应链等有方向的假设边；每条边记录依据、时间范围、成立条件、反例和置信度依据。
4. **对象层**：大盘、科技子行业、具体公司分别受什么影响，正/负/混合/未知，以及需观察的验证信号。

“新闻语气”“作者表达的恐慌或乐观”“模型判断的经济影响”“实际市场反应”是不同变量。支持方向的证据与模型推断分别保存。未校准的模型置信度不能写成上涨概率。

候选观察窗口为1、5、20个交易日，尚未冻结金融协议。更长的建设/资本开支渠道另注明数月尺度。日内影响需要分钟级发布时间和价格，日线不能验证分钟级传导。

## 4. 连锁反应：条件图，不是确定性预言

例如，假设通胀公布值高于公布前可信共识：可能引起政策路径重估，并影响利率与科技估值；但若市场早已预期、增长信号更强或数据分项不一致，反应可以不同。观察到收益变化也不自动证明某条新闻是原因。

假设融资条款收紧：企业融资成本→扩张计划→设备订单是一条待检验路径；长期已签约订单、现金储备、客户预付款或替代融资均可能削弱它。节点与每条边分别标为来源明确、根据暴露推断或尚未验证，不让模型凭空画多跳关系。

第一版每条情景路径最多两跳，最多三个候选路径；这是产品范围，不是证实因果的规则。将支持情景、反向情景及下一条验证信号同时显示。模型负责提出证据支持的假设，数值计算与身份匹配由程序负责。

## 5. 数据与时间

以BLS发布/日历、Fed决议/讲话、公司IR/SEC文件等核验事件；新闻聚合源用于发现和补充叙事。金十和HF是候选传输渠道，只有核验具体产品、历史覆盖、时区、首次发布时间、修订和保存权限后才作为输入。账户可用不代表全历史或正文权利已确认。

CME FedWatch反映期货价格隐含的利率概率，不是Fed的承诺。概率必须带会议日期、动作定义与截面时间；历史快照缺失时不能拿今天页面回填。BLS实际发布不等于调查共识；共识须另找有公布前时间依据的来源。ALFRED历史版本有助于记录修订，但仍需核验具体系列及日内可用时间。

正文、数值、预期、时间、来源都保留版本。对同一事件多篇报道建立event_cluster；不把重复报道数量当事件规模。实时收集需要另行配置服务，本路线不意味着已启用后台监控。

## 6. 选样和评价

首轮目标是12张可人工判断相关性的候选事件卡：上述六类各争取两张，优先在2026-05-15至执行时点的公开材料中寻找。该配额是开发材料目标，不是研究样本量；不足即报告不足，不拼凑事件。只选当时可判断的重要性，不因事后股价大跌或大涨而入选。记录无反应/反方向/低意外度事件，避免只看“轰动案例”。

用户先点选关注度与是否保留，属于偏好筛查，不是事实金标准。随后真人裁定事实、预期比较、目标公司、方向及每条传导边的依据。历史回溯样本和未来前瞻日志分开；模型checkpoint锁定不等于训练截止已知。训练截止不明或晚于历史事件时，只能称回顾性分析。

正式金融评估另建连续、规则化事件面板：预先登记全部计划发布，非计划新闻按固定来源和事前规则纳入；按事件簇、时间划分训练/验证/测试。基线至少包括价格/波动率历史、数值surprise、简单词典/文本方法；逐步增加直接公司新闻和跨公司渠道信息。先检验波动率/风险的增量信息，再考虑方向、协方差与策略。没有准入数据就不运行标签和回测。
