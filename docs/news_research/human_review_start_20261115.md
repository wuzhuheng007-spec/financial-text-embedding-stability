# 前十篇新闻：点选式人工筛查 / Click-only article review

**状态：审阅者已认领，人工选择仍为 0/10。** 用户已表示由本人填写。此页只说明操作，不包含新闻原文、模型回答或人工标签。

本机入口（以仓库根目录为基准）：`artifacts/news_targeted_repair_20261115/human_review_original_first10_v1/review_choices.html`。页面在左侧显示既有十篇原文，在右侧提供选项。**无需手写文字。** 旧 `index.html`、十篇原文页、`blank_review_template.jsonl` 和尚未填写的 `review_working_copy_20261115.jsonl` 均保留；新页面不会改动它们。[界面回执](../../results/news_constrained_decode_20261115/human_choice_ui_receipt.json)绑定样本、原审阅清单和私有页面哈希。

1. 打开 `review_choices.html`。按 01–10 读左侧原文，再点右侧选项。六道核心题依次检查：能否识别公司、是否有事件、**新闻语气评分**、**对公司经营的影响方向**、原文是否支持判断、把握程度。语气与经营影响分开；都不是股票收益预测。
2. 如愿意，再点两道可跳过题：直接/间接影响、正文明确陈述/个人推断。对多家公司或多个事件，可在核心题直接选“多个”；不确定就选“无法判断”。页面另有一次性的“此前是否看过模型输出”选项，用于披露审阅来源。
3. 每篇点完可切换到下一篇。页面会尝试保存在当前浏览器；因 `file://` 浏览器行为可能不同，请定期点“下载当前选择 JSON”保留本机副本。再次打开时可点“导入已保存选择 JSON”，导入时会核对样本与文章哈希。导出内容只有序号、哈希和选项，不含新闻正文。

**边界：** 这是文章级人工筛查，并未记录逐字引用位置或逐个公司—事件对。若有多事件或证据只能部分支持，后续仍须按版本化结构做更细的真人裁定；本页的选择不能直接称为完整 gold 或抽取准确率。原文、下载的选择文件及后续人工标签均留本机私有目录，不上传 GitHub 或交接 ZIP。历史证券身份、市场时间、价格和金融收益评估仍未准入或 `NOT_RUN`。
