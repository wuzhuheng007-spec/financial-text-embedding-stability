# Market-observer source and permission register

Checked 2026-11-15, Asia/Shanghai. This register separates public documentation from capabilities actually observed in this account. A successful MCP configuration is not a quote entitlement, a push subscription, or permission to republish data.

| Official source | Documented fact | Account-specific or project gap |
| --- | --- | --- |
| [moomoo MCP quick start](https://open.moomoo.com/mcp-docs/quick-start) | Streamable HTTP endpoint `https://mcp.moomoo.com/mcp`; first connection uses browser OAuth. Claude/Cursor examples are client-specific. | The fresh Codex CLI, not this already-running desktop session, performed the bounded calls in the [connection receipt](../../../results/market_observer_v1_20261115/moomoo_connection_receipt.json). |
| [moomoo MCP authentication](https://open.moomoo.com/mcp-docs/authentication) | `quote:read` covers quotes, historical candles and market data; `trade:write` authorizes order actions. | The user approved an explicit `quote:read` request and the login succeeded; a separate granted-scope readback was unavailable. No balance, holdings, orders or trading calls were made. |
| [moomoo MCP available tools](https://open.moomoo.com/mcp-docs/available-tools) | Gives read-only quote/candlestick examples; published Tool List is dynamically rendered and the static page says `Loading…`. | A fresh CLI registry reported 104 bindings and exposed quote, calendar, news search and earnings tools. Raw `initialize` and `tools/list` RPC receipts were unavailable; business calls tested only security information and one quote. No separate body or push tool was observed. See the [capability matrix](../../../results/market_observer_v1_20261115/moomoo_capability_matrix.json). |
| [moomoo WebSocket quote push](https://open.moomoo.com/api/quote/push/subscribe), [authentication](https://open.moomoo.com/api/quote/push/auth) | The distinct OpenAPI surface supports subscriptions including 1-minute candles after WebSocket auth; reconnection requires authentication and resubscription. | A Codex MCP OAuth token is not assumed exportable to a standalone service. Account entitlement, actual quota and credential path have not been validated for push. |
| [moomoo market permissions](https://open.moomoo.com/api/overview/api-authority), [subscription quota endpoint](https://open.moomoo.com/api/quote/quotas/subscription) | API rights can differ from app rights; subscription capacity is account-specific. Example totals are not an account quota. | No purchase or paid subscription in this project. A quote response may be delayed or unavailable. |
| [moomoo terms](https://www.moomoo.com/terms) | Market data are for authorized personal use and redistribution is restricted. | Retention and research reuse need the applicable provider/account terms; no raw market data are pushed to GitHub. |
| [Jin10 source and use boundary](../jin10/source_rights.md) | Prior bounded MCP intake and private local store are documented. | Polling frequency, retention and redistribution rights remain unconfirmed. No unlimited news poll. |

Handling: private SQLite and provider responses stay under ignored `artifacts/`. Public outputs contain code, configuration templates, hashes and non-content aggregate receipts only. The local dashboard must distinguish missing coverage, closed markets, delayed quotes, stale messages and genuine absence of a completed response. First local receipt is not original publication time. A market move does not verify a news claim.
