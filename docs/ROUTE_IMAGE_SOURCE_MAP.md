**Source caution.** The screenshots make broad claims about benchmark authority, larger models, hybrid superiority, reranker gains and knowledge graphs. Those claims are not adopted as results. The original [MTEB paper](https://aclanthology.org/2023.eacl-main.148/) explicitly reports no method dominates all tasks; the [C-MTEB introduction](https://arxiv.org/abs/2309.07597) concerns Chinese embeddings, whereas this saved corpus is English. The [HyDE paper](https://aclanthology.org/2023.acl-long.99/) describes hypothetical-document generation for zero-shot retrieval; it is not implemented here. [Lost in the Middle](https://aclanthology.org/2024.tacl-1.9/) reports position sensitivity in studied long-context tasks, not a measurement of this project's unrun generator. The [IR measures reference](https://ir-measur.es/en/latest/measures.html) distinguishes Recall@k from Success@k and defines ranking measures requiring relevance judgments. RAGAS, ARES and TruLens are mentioned as candidate evaluation frameworks in the images; they were not used in M10.

The [proposed technical roadmap](PROPOSED_TECHNICAL_ROADMAP.md) separates what the images suggest from the project's current implementation and from new research-team decisions. No screenshot file is included in the Git tree.
