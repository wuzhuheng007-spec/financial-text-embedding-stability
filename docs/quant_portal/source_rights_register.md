The public backend enforces this register through a deny-by-default display flag on shared content. The current personal mode uses a separate ignored, owner-ID-bound cache; only that owner may read it on `127.0.0.1`, and no `LICENSED_PUBLIC` or `display_approved` flag is set by this connection. Page refresh reads the cache only. Provider adapters and model workers are not enabled by a user visit. Source time, receive time, delay and stale state remain distinct. `dot` remains disconnected until verified independently.

Before any live invited-user release with provider content, record the written permission, exact product/fields, recipient class, retention, territory, rate limit, display wording, AI use and redistribution conditions; update the implementation gate and test it. No such provider permission is recorded in this round.
