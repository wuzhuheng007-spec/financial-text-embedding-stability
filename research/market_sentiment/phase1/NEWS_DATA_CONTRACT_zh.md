# 新闻反应因子：输入与验证合同 v0.1

状态：研究提案，尚未计算、训练或验证。价格基线与新闻变量分开保存。先用真实、可回溯的短样本试点，再按可获得的存档扩展，不构造不存在的早期社交媒体或一致预期。

## 必须具备的数据

| 字段 | 规则 |
|---|---|
| event_id / canonical_event_id | 事件与去重事件的稳定标识；同一财报的多篇转载不当成多个独立冲击 |
| source_url / snapshot_sha256 | 原文来源与快照哈希；保留原文版本，不能只保存模型摘要 |
| first_public_at_utc | 第一次对外公开的真实时刻，不能拿抓取时间代替 |
| captured_at_utc / revised_at_utc | 实际抓取及修订时间；修订文本不得回填到首发时点 |
| market / issuer / event_type | 美国或中国；宏观、政策、财报、融资、治理等类别分列 |
| expected_value / expectation_asof / expectation_source | 事件前已存在的预期及时间、来源；缺失时不声称“超预期” |
| actual_value / units | 真实公告数值、计量单位及对应报告期间 |
| ex_ante_direction / intensity / confidence | 根据原文及预期事前确定方向和强度；不能按事后涨跌修改 |
| model_id / revision / prompt_sha256 / training_cutoff | 若使用语言模型，记录模型与提示版本、已知训练截止；历史知识泄漏单列审计 |
| response_start / response_end / response_available_at | 价格反应窗口及其真正结束时刻；窗口没结束时不能使用完整反应 |
| price_reference / raw_price_ids | 与行情行级来源配对，明确公告前后、盘前盘后、休市和时区 |
| coverage / exclusions / missing_reason | 记录未覆盖和歧义，不能把缺失当成中性情绪 |

## 两个候选量分开研究

先在每个历史训练截止，用当时已有的同类型事件、预期差、强度、公告时段和事前价格状态估计通常反应。定义事件反应残差为“观察反应减训练样本预期反应”，再按仅用过去数据估计的波动尺度标准化。

- **利空承受能力**：对事前标为负面的事件，残差持续偏正，表示跌幅比同类事件通常反应更小。
- **利好兑现能力**：对事前标为正面的事件，残差持续偏负，表示上涨比同类事件通常反应更弱。

候选聚合窗口为 4/8 周，进入执行前另行冻结，并规定最少独立事件数。不得把一条重大新闻的许多转载当作事件数量充足。两种量不强行合成固定权重总分。

宏观/大盘事件和个股事件分开建模。个股反应可以用事前估计的市场/行业暴露调整；大盘反应不能先把大盘变化全部减掉，再解释为大盘情绪。跨个股汇总时保留权重、集中度和独立发行人数量。

## 如何检验增量

在相同日期、相同标的与相同成熟未来窗口内比较：价格基线、价格加文本语气、价格加预期差、价格加消息反应残差，再加入融资/信用条件。缺失新闻的日期必须同时从比较组剔除，防止覆盖差异冒充提升。

所有标准化、预期反应模型、降维与参数选择均在历史训练窗口内完成。训练标签必须在截止前成熟，跨分段的标签剔除；语料修订、模型版本与事件重复单列检查。评价 4/8/12 周价格分布、下行路径、校准和误报，之后再讨论可交易总回报与成本。

不能提前作出的结论：高恐慌必然反转、坏消息失效必然转牛、某次 IPO 必然抽走其他股票的资金、利好未上涨必然是情绪见顶。上述都需要事件强度、预期差、其他同期冲击及融资约束的证据。
