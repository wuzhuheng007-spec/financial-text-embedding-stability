整理日期：2026-11-19（北京时间）。行情截止：2026-11-17，各市场本地日期。

本轮已验收并合并 5 段补抓数据，新增 1,227 行。原始压缩包未改动，已知缺失没有填值。交付物支持价格描述和后续基线研究；尚未完成新闻情绪因子、可交易收益回测或预测有效性验证。

这里的“验收”指文件完整性、原始响应对账和明确的研究筛选规则，不代表逐日价格都经过另一家行情源独立确认，也不代表历史序列已无遗漏。

## 4. 保留的缺口和隔离规则

### SOX 仍有候选缺失日

2000-01-03、2000-03-01、2000-03-02、2000-03-03、2000-03-06、2000-08-28、2009-08-11。

这些日期相对本包实际存在的 QQQ 日期缺失，定向复查仍返回空。尚未用独立的 SOX 历史交易日历逐日认证，故称为候选缺口。数据库不生成虚拟观察值；单独的 unresolved_dates 表记录它们。价格图仅用 NaN 中断连线，没有写入价格。涉及这些日期的日收益、滚动窗口或持有期标签，后续应按预先约定的缺失规则置空或排除，不能把相邻两条记录自动当成相邻交易日。

### 上证综指异常与日历矛盾

- 原源及补抓均包含 2014-12-20（周六）日线，OHLC 都为 3188.25。原观察保留在 observations 和 merged CSV，研究日线排除该行；标签为 2014-12-15 的供应商周线也隔离。上交所交易安排明确周一至周五交易，节假日等除外。[S1]
- 供应商日历漏掉 2015-06-24，但原日线及补抓均有该日价格。上交所《统计年鉴 2016 卷》印刷页 10、PDF 第 14 页的每日上证收盘指数记载该日收盘 4690.15，故保留该日，不能机械套用供应商日历删掉。[S2]
- 供应商日历把 2001-07-04 列为美股交易日；NASD 当时公告明确该日 Nasdaq 和证券交易所休市。这个日历错误本身不表示本包存在该日 QQQ 价格，也不能用它证明价格缺失。[S3]

异常周六还会影响后续供应商 last_close/change_rate 的解释。数据库 vendor_fields_json 保存供应商字段以便审计；研究收益应另行用已接受的价格和明确的交易日/复权规则计算，不能直接使用供应商涨跌幅字段。

### 科创50发布前历史与未结束周

上交所公告称 2020-07-22 收盘后发布历史行情、7 月 23 日正式发布实时行情。[S4] 本版本采用保守的实时发布日起点，排除发布前 133 条日线和 28 条周线，避免把回溯历史误当作对应历史日期已公开的指数。原始记录仍保存。这项排除没有把整份数据变成 point-in-time 数据。

各标的标签 2026-11-16 的周线在截止日 2026-11-17 尚未走完一周，4 条均从研究视图排除；供应商周线最后收盘也不应被当作截至周二的最终周收盘。排除合计 167 条：周六日线 1、相关异常周线 1、未完成周线 4、科创50发布前日线 133、发布前周线 28。

### 其他口径

指数的成交量、成交额定义及零值含义尚未验证，保留为 *_raw 字段，不能直接据此构造情绪成交因子。原 time_key/time_zone 原样保存；available_after_local_date 对日线取本地日期、对周线取标签加四个日历日，只是名义日期标记，不是精确可交易时刻，也未完成中美跨市场 UTC 对齐。周五节假日等情况还需正式交易日历处理。

## 5. 文件与读取方式

| 文件 | 用途 |
|---|---|
| market_research.sqlite | 完整观察值、来源、质量标记及筛选视图 |
| csv/merged_*.csv | 保留异常和发布前记录的合并数据，每行含研究资格及来源 |
| csv/research_*.csv | 本版本筛选后的数据，仍受本报告限制 |
| audit/row_provenance.csv | 行级 ZIP 哈希、成员文件、JSON 指针 |
| series_registry.json | 所有序列的精确行数及日期范围 |
| merge_policy.json | 合并前固定的规则及限制 |
| merge_receipt.json | 实际合并回执和构建代码哈希 |
| input_lineage.json | 两个输入 ZIP 的文件名和完整 SHA-256 |
| audit/post_merge_self_check.json | 对原始响应逐行对账及 CSV 一致性自检 |
| audit/evidence_ledger.json | 报告主要论述与证据对应 |
| audit/runtime_and_code.json | 本轮软件版本、代码和配置哈希 |
| market_history_overview.png | 四个标的的价格水平概览，各图时间范围不同、纵轴为对数 |
| reproduce/ | 离线构建、自检和作图代码 |
| PACKAGE_SHA256.json | 包内载荷校验清单，不包含清单自身 |

SQLite 的 observations 表保留完整供应商记录 JSON；research_daily 和 research_weekly 视图只选择 research_eligible=1。同一标的的不同复权、日线和周线不可拼成单一时序，也不能重复计为独立市场证据。

例如，读取 QQQ a1 日线：

```sql
SELECT local_date, close, flags_json,
       source_archive_sha256, source_member, source_pointer
FROM research_daily
WHERE symbol='US.QQQ' AND autype=1
ORDER BY local_date;
```

查询 SOX 候选缺口：

```sql
SELECT * FROM unresolved_dates ORDER BY local_date;
```

本包不重复嵌入两个输入 ZIP。它们的身份由完整哈希固定，逐行价格必须回到这些输入包的原始行情响应验证，不能只比较两个由同一代码生成的派生文件。

## 6. 可选的本地复现

本轮已执行构建和检查，无需再次登录授权。以下只供以后重建，不调用 moomoo，不读取账户或令牌。构建、自检仅依赖 Python 标准库；作图另需 matplotlib，本轮版本见 audit/runtime_and_code.json。

1. 将本交付包解压为 `E:\moomoo_US_OpenAPI_readonly_setup\moomoo_research_v0_1`，确保直接打开该目录能看到 reproduce 和 market_research.sqlite。
2. 保留两个原输入 ZIP 在其上一级目录，文件名须与 input_lineage.json 一致。
3. 在 PowerShell 切换到数据包目录：

```powershell
cd E:\moomoo_US_OpenAPI_readonly_setup\moomoo_research_v0_1
```

4. 构建到一个尚不存在的目录。脚本会校验输入身份，并拒绝覆盖已有输出目录：

```powershell
py -3 .\reproduce\build_dataset.py --original ..\moomoo_history_20261118T214803Z_41e00a.zip --patch ..\moomoo_patch_20261118T221352Z_fa2b41.zip --out .\rebuilt_v0_1
```

5. 对重建数据库及 CSV 做自检，结果写入重建目录的 audit/post_merge_self_check.json：

```powershell
py -3 .\reproduce\verify_dataset.py --original ..\moomoo_history_20261118T214803Z_41e00a.zip --patch ..\moomoo_patch_20261118T221352Z_fa2b41.zip --dataset .\rebuilt_v0_1
```

6. 如果已安装 matplotlib，可重新作图：

```powershell
py -3 .\reproduce\plot_history.py .\rebuilt_v0_1
```

重建输出只包含脚本生成的数据与审计文件；本说明、证据台账及打包清单属于交付文档，不由构建脚本自动再生。数据库逻辑内容可复核，不承诺跨 Python/SQLite 版本的二进制逐字节相同。

## 7. 接下来的研究边界

本轮没有新训练模型、选择最佳参数或检验收益。价格变化本身不能区分情绪、盈利预期、利率冲击与流动性冲击。缺少当时可获得的新闻原文、发布时间、盈利预期、调查或持仓等输入时，不能宣称已测出“情绪拐点”。

下一阶段建议先固定研究协议：美国与中国分别验证；从价格趋势、回撤、实现波动率等基线出发；中期目标采用事先确定的 4/8/12 周窗口，明确价格回报和总回报差别。新闻因子的候选方向是相似信息冲击后的市场反应是否逐渐变化，例如坏消息下跌幅收敛或好消息上涨乏力；该方向目前只是待检验假设。

应提前固定历史案例选择方法，覆盖成功反转和失败反弹；有时间顺序的样本外验证、重叠持有期处理、阈值敏感性及成本检验后，才讨论预测价值。QQQ、SOX、科创50之间存在市场/行业重叠，不是多次独立复制。尚需补充经过授权、具有当时可用性记录的新闻及外部状态数据；无需为本轮合并再运行授权脚本。
